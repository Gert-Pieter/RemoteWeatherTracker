# Remote Weather Tracker
This is a website where you can select a area to get weather information about area where you select from. It adds more areas.

# Why?
A family member from a remote location wants to track their area weather information as well as their job weather information.

# What makes this one different
Physically select a point on the map, this allows to you to add more then two locations at once.

# API's

| API name                                                     | Information                                                                                                                                                                                          |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Open Metro](https://open-meteo.com/?utm_source=chatgpt.com) | Weather API that uses 30+ models from different nations weather services. In my project I use ICON as it is one of the models that provides global data. It uses satellites data to do the tracking. |
| [Leaflet Map](https://leafletjs.com/)                        | Map API that gives a canvas map, it can also return the user latitude and longitude which is why I use it for this project                                                                           |
